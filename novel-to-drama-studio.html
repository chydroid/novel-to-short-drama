为什么必须先做这一步

每个镜头单独文生图 = 每一镜都在重新抽卡，主角长相、教室布局必然漂移。
正确做法：先给每个角色生成一张「定妆照」、给每个场景生成一张「空景图」；之后所有分镜生图时都把这两类图作为参考图（多图合成），同时把外貌 / 布局描述作为固定文字锚点注入提示词。
顺序别反：① 拆镜 → ② 生成设定图 → ③ 再生成分镜图。

角色卡

角色卡会生成一张全身定妆照（中性背景）。「英文锚点」是长相一致的关键，要写清：年龄、性别、发型发色、面部特征、常穿服装与配色。

场景卡

场景卡生成一张无人的空景广角图。之后同一间教室的所有镜头都以它为参考，保证课桌、门窗、黑板不换位置。

模块四 · 成片时间线

两条出片路线：①「一键合成包」导出 FFmpeg 脚本，配合字幕 + 整轨配音直接合出带字幕、带 BGM 的 成片.mp4（脚本直接读取各镜的公网 URL，需本机装有 FFmpeg）；② 时间线路线：导出「剪辑时间线 .fcpxml」，先跑一次合成脚本把各镜落盘成 seg_N.mp4，再导入 Premiere / 达芬奇 / Final Cut，镜头顺序、时长、台词都已排好；③ 手动路线：把各镜视频按顺序拖进剪映 / PR，再对齐整轨配音与字幕（都按每镜实际音频时长排时间轴，对齐 0 点即可音画同步）。

设置

Agnes 图片 / 视频 API
并发与多 Key 轮换
批量生成默认串行较慢。这里可调并发路数与失败自动重试；多个 Key 每行一个会自动轮换，遇到 429 限流 / 401 鉴权失败自动换下一个 Key 重试，适合多账号分摊配额。
一致性增强（决定角色 / 场景会不会漂移）
配音 · 小米 MiMo TTS（限时免费）
在 platform.xiaomimimo.com 申请 TTS 专用 API Key（与模型推理 Key 不通用）。浏览器直连会被跨域拦截，建议 TTS Base URL 填本地代理：http://127.0.0.1:8787/tts/v1（启动代理时加 --tts https://api.xiaomimimo.com）。
语速只用于「质检」时估算台词需要几秒，默认 4.5 字/秒；念得慢的旁白可下调。
口型同步（可选，需第三方唇形服务）
先说清楚原理：agnes-video 是「首帧图 + 提示词」驱动，不接收音频，所以生成的画面嘴型天然对不上配音。目前有三条路，建议按序使用：
① 镜头规避（免费，强烈推荐）：在「生成图/视频」页点「AI 规避改写」，把高风险的「正面说话特写」自动改成过肩 / 侧脸 / 反应镜头 / 手部特写，嘴部不明显就不需要口型。
② 唇形服务（本配置区）：填一个支持「视频 URL + 音频 URL → 对口型视频」的服务端点，生成视频后自动提交合成，结果写回该镜。
③ 剪映后期：导出对齐好的整轨配音 + SRT，用剪映的「文本朗读/对口型」或手动微调。
背景音乐 BGM
成片输出（影响一键合成包脚本）
转场与运镜在 FFmpeg 合成时生效
导出「整轨配音 .wav」时会自动把 BGM 循环铺底、按音量混合并做首尾淡入淡出；一键合成脚本里也会带上这条 BGM。
字幕样式（烧录进成片时生效）
颜色用 ASS 的 BGR 顺序：白色 = FFFFFF，黄色 = 00FFFF。改完重新导出合成包即可，不影响的 .srt 本身。
