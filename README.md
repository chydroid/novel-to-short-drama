# 小说转短剧工作台（Novel to Short-Drama Studio）

把小说一键流水线化成 AI 短剧的单文件 Web 工作台：**小说原文 → AI 拆镜 → 角色/场景设定图 → 分镜图 → 分镜视频 → TTS 配音 → 字幕/整轨配音/FFmpeg 一键合成成片**。

单文件 HTML，全内联零外部依赖，PC / 移动端自适应；数据云端同步（WorkBuddy 资料库）+ 本地 localStorage 双通道，离线自动降级。

## 功能总览

| 模块 | 能力 |
|---|---|
| ① 剧本拆镜 | 粘贴小说 / 导入 txt，AI 拆出画面描述、英文提示词、运镜、景别、说话角色、情绪、台词、时长；自动创建设定卡 |
| ② 角色与场景 | 角色卡（定妆照 + 面部特写 + 常服 + 性格 + TTS 音色）、场景卡（空景图 + 反打机位）；一致性体检面板（0–100 分） |
| ③ 生成图 / 视频 | 多视图参考图 + 文字锚点出图；图生视频；满意基准帧锁定、失败重试、批量生成 |
| ④ 成片与导出 | 时间线总览、字幕 .srt、整轨配音 .wav、FFmpeg 一键合成包（render.sh / render.bat / 合成清单.json） |

核心特性：

- **五层一致性方案**：多视图设定图（副视图以主图为参考生成）、参考图优先级与上限、满意基准帧机制、服装/景别/情绪三重文字锁定、一致性体检
- **长篇流水线**：整本小说按「第 X 章」自动切分，勾选后一键跑完 拆镜 → 设定卡 → 设定图 → 分镜图 → 配音 → 视频；跨章全局词表锁定人名；支持断点续跑
- **章节 AI 剧本化**：正文改写成对白化、强钩子的短剧剧本后再拆镜，可一键还原
- **音画同步**：配音返回后镜头时长自动对齐语音长度；字幕与整轨配音共用同一时间轴
- **口型处理**：口型风险判定（景别 × 说话人）→ AI 规避改写（过肩/侧脸/背身）→ 可选第三方唇形服务
- **BGM 轨**：配置 URL / 音量 / 淡入淡出，WebAudio 混入整轨配音，合成脚本同步支持
- **用量与成本追踪**：生图张数 / 视频秒数 / 配音条数 / 口型次数自动计数，可填单价，所有批量操作前弹窗预估费用
- **AI 从小说提取设定**：读全文自动输出角色 / 场景结构化设定卡（含英文锚点与 TTS 音色建议），预览勾选后批量写入
- **分镜质检 Agent**：一键体检整张分镜表（时长越界 / 台词念不完 / 缺设定卡与图 / 生成失败 / 口型风险 / 连续同景别 / 全片过短），逐条带一键修复
- **光影与结构化外观**：分镜可填光影 / 时间 / 天气注入画面提示词；角色外观结构化（发型 / 上装 / 下装 / 配饰）自动拼装服装锁
- **提示词查看 / 改写**：看最终送给模型的完整提示词，可改写覆盖、可一键还原
- **字幕样式可配**：字体 / 字号 / 颜色 / 描边 / 边距 / 加粗，应用到合成脚本烧录
- **导出剪辑时间线 .fcpxml**：可直接导入 Premiere / 达芬奇 / Final Cut，镜头顺序与时长已排好
- **并发批量队列**：批量生图 / 视频 / 配音 / 口型并发执行，可调并发路数（1–8）与失败自动重试（0–3，指数退避）
- **多 API Key 轮换**：多个 Key 轮询使用，遇 429 限流 / 401 鉴权失败自动换下一个重试，抗限流
- **风格预设库**：8 套视觉风格（写实电影感 / 国风古装 / 日系动画 / 3D 动画 / 水墨国漫 / 赛博朋克 / 黑白悬疑 / 青春校园）一键切换
- **分镜编辑**：上移 / 下移 / 复制 / 插入空镜并自动重编号，支持撤销（按钮或 Ctrl+Z）
- **一键打包与范围导出**：导出中心把字幕 / 脚本 / 清单 / 数据 / 转码命令一次打成 .zip（可选连整轨配音，也可**附带体检报告 / 剩余清单**），并支持「全部 / 仅已完成 / 跟随筛选 / 仅勾选章节 / 自定镜号」五种范围，导出前实时预览「几镜 / 多长 / 多大」（含**分文件体积明细**与整轨压缩建议，zip 容器开销也计入），包内附打包说明；v2.22 修掉了自写 zip 的多文件偏移错误（此前第 2 个文件起在解压软件里会报错）；v2.23 起可勾选只打哪几样文件（字幕 / 脚本 / 清单 / 数据 / 转码命令可分别勾选），不必整包都打
- **自定镜号表达式**：支持多段与排除（`1-20,25,30-35` 并集、`1-50,!8-10` 排除、`8-` / `-20` 开区间），**v2.20 起可用 `#章节名` 直接引用整章**（`1-100,!#第一集`），**v2.22 起可用 `@预设名` 引用别的预设**（`1-20,@片头,!@片尾`），写错的段自动忽略；常用表达式可**存为命名预设**一键套用、可**上移排序**，预设按钮上标注**当前命中镜数**（v2.21）并可点「筛」直接到生成页只看这几个镜（v2.22）；镜号预设也能导出 / 导入 JSON（v2.23），换设备不必重填
- **剧集画面类型 + 套餐库**：选「现代都市 / 古装年代 / 动画二次元」后，既按题材调评分阈值，也把对应画风写进生图 / 生视频提示词；内置 3 套类型套餐（画风 + 全局令牌 + 提示词注入）一键套用，并支持**把当前配置存成自定义套餐**，可套用 / 删除；自定义套餐可**导出 / 导入 JSON**（v2.22），换设备或多人共用一套配方不必重配
- **批量断点续跑**：批量生图 / 视频 / 配音中途暂停后，剩余镜号**按类型分别**写进本机存档，三类可同时续跑；首页按类型列出「续跑」卡片，可「只跑剩余镜」直接按存档镜号投队列、「去定位」跳转、「存为选区」把剩余镜号压成区间存成镜号预设（v2.21）、或**导出剩余清单**（CSV + BOM，Excel 直接开不乱码）；生图与生视频同时有剩余时可一键**「图→视频 串跑」**（先补图 → 自动接生视频，v2.22）；v2.23 扩到「图→视频→配音」三段，可顺带对口型，三类都有剩余时一次性接力跑完
- **批量跑前预检**：生视频缺图片、配音缺台词的镜头在开跑前即被剔出，不占进度、不计失败，并明确提示跳过数量与原因
- **关键字段体检**：逐镜检查缺画面描述 / 无生图提示词 / 没时长 / 没章节 / 有台词没角色，分硬性软性两档；首页在有硬性缺料时给出体检卡，可「去修第一个」直接定位（v2.21）、查看明细或导出报告（TSV 或 **.xlsx**，后者可在 Excel 里直接排序筛选，v2.22）
- **自带 xlsx 导出**：xlsx 本质是 zip + 几段 XML，复用自写的 zip 实现**零外部依赖**生成工作簿（数字走数值单元格，可排序）；体检报告与剩余清单都能导成 .xlsx，剩余清单一类一张工作表（v2.22）；v2.23 起表头加粗、冻结首行、列宽自适应，在 Excel 里下滑不丢表头、列宽刚好够看
- **生成页多套筛选视图（v2.23）**：把当前筛选条件（全部 / 未生图 / 按镜号选区等）存成命名视图，生成页顶部出现视图 chips，点一下即切回那套筛选并恢复当时的滚动位置；常用几套视角（如只看未生图、只看某镜号选区）不必每次重选，多人协作也能共享同一套「只看这片」的视角；v2.24 起可 **✎ 重命名**、**拖拽排序**（顺序即 `cfg.filterViews` 数组、直接落盘），常用视角自己排
- **成片镜头语言**：图片垫段 Ken Burns 推拉运镜、段内淡入淡出转场、输出帧率与码率可配

## 快速开始

1. 下载 `novel-to-drama-studio.html`，浏览器直接打开（或使用在线部署链接）
2. 启动本地 CORS 代理（零依赖，仅 Node）：

   ```bash
   node agnes-proxy.js --text https://api.deepseek.com --tts https://api.xiaomimimo.com
   ```

3. 页面「设置」里填四组配置（只存本机浏览器）：

   | 配置项 | 值 |
   |---|---|
   | Agnes Base URL | `http://127.0.0.1:8787/v1` |
   | 任务查询根地址 | `http://127.0.0.1:8787` |
   | 文本模型 Base URL | `http://127.0.0.1:8787/text/v1` |
   | 小米 TTS Base URL | `http://127.0.0.1:8787/tts/v1` |

   再填入 Agnes API Key、文本模型 Key、小米 TTS Key（platform.xiaomimimo.com 申请，与推理 Key 不通用），用三个「测试」按钮逐个验证。

4. 按顺序使用：**① 拆镜 → ② 设定图 → ③ 分镜图/视频 → ④ 配音 → ⑤ 成片导出**

## 一键合成成片

「成片与导出」点「一键合成包」，得到 `render.sh`（macOS/Linux）、`render.bat`（Windows）与 `合成清单.json`；配合「导出字幕 .srt」「导出整轨配音 .wav」（改名为 `subs.srt` / `voice.wav` 放同目录），安装 [ffmpeg](https://ffmpeg.org) 后运行脚本即可产出 **成片.mp4**（视频段拼接 + 缺视频镜头图片垫段 + 人声/BGM 混音 + 字幕烧录）。

## 技术说明

- **生图**：`agnes-image-2.5-flash`（`response_format` 须放 `extra_body`；多参考图经 `extra_body.image[]`）
- **生视频**：`agnes-video-2.5-flash`（keyframe 模式，`seconds` 4–12 秒，异步轮询）
- **配音**：小米 MiMo TTS（OpenAI 兼容接口，待合成文本须置于 `assistant` 角色）
- **数据**：分镜与设定卡存 WorkBuddy 资料库数据表（多设备同步）；API Key、小说原文、音频本体只存本机 localStorage。配音音频仅存在于生成它的设备，换机请重新生成或导出整轨
- **代理**：只监听 127.0.0.1，纯 Node 内置模块实现，无任何 npm 依赖
